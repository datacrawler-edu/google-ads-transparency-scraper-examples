# Output reference

Dataset rows identify a public advertiser and creative. Core fields include `advertiserId`, `advertiserName`, `creativeId`, `adFormat`, `firstShown`, `lastShown`, `approxDaysShown`, `adUrl`, `previewUrl`, `matchedDomain`, `searchQuery`, and `scrapedAt`. When enrichment succeeds, `previewFetched`, `previewText`, and `previewAssetUrls` are also present.
