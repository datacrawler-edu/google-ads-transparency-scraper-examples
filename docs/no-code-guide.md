# No-code guide

1. Open the [hosted Actor](https://apify.com/datascraperes/google-ads-transparency-scraper?fpr=edudata).
2. Enter a domain, advertiser name, or advertiser ID in `searchQuery`.
3. Set `maxResults` and optional platform, format, country, and date filters.
4. Enable `includeDetails` only when preview text or assets are useful.
5. Click **Start**, then inspect or export the Dataset.
